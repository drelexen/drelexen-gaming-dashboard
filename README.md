# 🎮 Drelexen OS - Interactive Gaming Dashboard

A premium, localized, full-screen interactive gaming portal built as a 10th-grade frontend engineering project.

## Key Features
- **Dynamic Background Shifting:** Custom ambient glow canvas that changes color themes instantly depending on user hover focus.
- **Embedded Local Image Assets:** 100% network-independent configuration that loads graphic cards flawlessly in offline environments.
- **Cinematic Transition Portals:** Features custom logic state loaders that execute a splash transition window before opening game ports.
- **Stealth Launch Architecture:** Fully portable batch shell (`launch.bat`) that triggers borderless edge-to-edge browser Kiosk layouts, terminating immediately upon pressing `Alt + F4`.

## Supported Titles
1. **Minecraft** (Classic Web Node)
2. **Roblox** (Discover Platform)
3. **Asphalt 9** (Official Gameloft Portal)
